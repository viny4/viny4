## About Me

Backend engineer at **[Trames](https://trames.io)**, working mainly with
TypeScript, Node.js, PostgreSQL and AWS.

Outside work, I build **[Orbica](https://orbica.space)** — an open space
encyclopedia covering rockets, satellites and launches since 1957, with
live 3D orbital tracking.

Previously built and shipped backend systems serving **~200K users** at
Thaagam Foundation using Django, PostgreSQL, Redis and the WhatsApp Business API.

Currently finishing an MCA alongside full-time engineering work.
